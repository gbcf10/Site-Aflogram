🖤 Afroglam — E-commerce Fashion

Afroglam é um projeto de e-commerce de moda fitness feminina, desenvolvido com foco em performance, experiência do usuário e arquitetura profissional.

O projeto está evoluindo de um modelo demonstrativo para uma loja virtual completa com autenticação de usuários e pagamento integrado.

🚀 Objetivo do Projeto

Desenvolver um e-commerce moderno com:

✅ Cadastro de usuários

✅ Login e autenticação segura

✅ Carrinho de compras dinâmico

✅ Finalização de compra no próprio site

✅ Integração com gateway de pagamento

✅ Controle de estoque em tempo real

✅ Área do cliente com histórico de pedidos
